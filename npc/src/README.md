# 将多周期cpu改进为流水线的结构设计

## 五级流水

问题： 

1.数据冲突
对于csr造成的冲突,由于目前没有tlb这个模块和特权级的概念，因此不需要提前读出，全部在wb级实现，无冲突

对于reg指令造成的冲突，
采取前递的机制，每一级讲明自己的写入寄存器，和写入数据，以及写入有效性，给id级读取使用

2.控制冲突

跳转指令控制冲突，
异常控制冲突，fence.i造成冲突

这三者导致在wb级外的指令无法确定是否真实发生

由于这三者均可以在exe级中全部解决，因此认为mem级和wb级全部有效

控制冲突的解决机制：

跳转指令冲突：
id级就能计算出跳转地址，采取静态预测的方式，如果不是pc+4，就发出冲刷请求

异常控制冲突：
exe级得出全部的异常信息，如果有异常，发出冲刷请求

fence.i控制：
在id级得出对应的fence.i指令，同时发出对应的fence_req和对应的冲刷请求
